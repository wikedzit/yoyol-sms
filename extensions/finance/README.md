# Finance

Fee items, class amounts, invoices, payments, receipts, and provider matching for one school.

Amounts are integer minor units. The outstanding balance is calculated from invoice lines and allocations. A payment is reversed by a new entry, and the original row stays.

The tables are `mod_finance_fee_items`, `mod_finance_structures`, `mod_finance_invoices`, `mod_finance_lines`, `mod_finance_payments`, `mod_finance_allocations`, `mod_finance_receipts`, and `mod_finance_provider_payments`.
