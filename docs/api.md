# API reference

The OpenAPI document is generated by `apiDocument()` in `workers/kernel/openapi.ts` and served at `/api/v1/openapi.json`.

The current document describes:

| Method | Path | Meaning |
|--------|------|---------|
| GET | `/api/v1/schools` | Schools the signed-in person belongs to. `limit` and `offset` page the list. `401` when nobody is signed in. |

Open `/api/v1/openapi.json` while the dev server is running to read the same document the app serves.
