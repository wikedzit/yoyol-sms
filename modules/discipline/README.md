# Discipline

Incident types, severity levels, and incident records.

An admin manages the lists and can see and close every incident. The teacher who recorded an incident can see and update it while it is open. A linked guardian can see incidents for their students. A student cannot. Each time an incident is shown, that view is written to the audit log.

The tables are `mod_discipline_types`, `mod_discipline_severities`, and `mod_discipline_incidents`.
