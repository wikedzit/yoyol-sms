# Security

Report a vulnerability in private. Do not open a public issue that includes a working exploit, a password, or a signing key.

Until a dedicated security address is published, contact the repository maintainers through a private GitHub security advisory on this repository.

Do not send:

- a live student or guardian record
- a private key or `AUTH_SESSION_SECRET`
- a session cookie

Say which version you ran, what you expected, and what happened. The rotation and revocation steps are in [docs/security-incidents.md](docs/security-incidents.md).
